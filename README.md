# RCP Lab

Локальная лаборатория эволюционного поиска Python-программ: цель → план → кандидаты → проверка в песочнице → принятая версия → следующий шаг. Веб-интерфейс, история проектов и чат на русском языке.

## Возможности

- Автопилот без фиксированного общего числа раундов, пауза и продолжение с сохранённого состояния.
- Чат: **Обсудить** — разговор о проекте; **Поручить** — приоритет следующего шага; **Проверить** — реальное выполнение принятой программы.
- Проверка старых и новых тестов перед принятием кода. Неудачные кандидаты не заменяют рабочую версию.
- Сохранение переписки и версий, восстановление после перезапуска модели и панели.
- Старый ручной режим на `/classic`: собственные тесты и ограниченный запуск OpenEvolve.

Модель подключается через локальный llama.cpp API `http://127.0.0.1:8081/v1`, алиас **`rcp-coder`**. Текущий профиль — **Gemma 4 12B IT, GGUF Q4_K_M**. Веса, бинарные файлы, CUDA-библиотеки и персональные данные в репозиторий не входят. Интернет для генерации и проверки программ не требуется после установки.

## Границы эксперимента

Автопилот создаёт Python-модуль с `solve(data)`: один JSON-объект на входе и один на выходе. Разрешена стандартная библиотека, вспомогательные функции и классы. Это не универсальный агент для развёртывания сайтов или управления машиной.

Модель может ошибаться, создавать неверные тесты или застревать. Прохождение тестов не доказывает правильность на всех данных. Нет гарантии постоянного улучшения при длительной работе. Текст чата — интерпретация модели; фактическая версия и результат выполнения показываются отдельно.

Код кандидата запускается через bubblewrap и prlimit: отдельные namespaces, без сети и устройств GPU, ограниченная файловая система, до 256 МиБ адресного пространства, лимиты CPU/времени/вывода. Это исследовательская изоляция, не гарантия против всех атак на общее ядро. Используй отдельную непривилегированную VM/LXC, не передавай секреты или Docker socket.

## Запуск на Linux / Ubuntu 24.04

Требуются Python 3.12, venv, bubblewrap, util-linux, git и работающие пользовательские namespaces. Не запускай панель от root. В некоторых окружениях AppArmor или контейнерный профиль блокирует bubblewrap — сначала проверь тесты, а не отключай защиту целиком.

```sh
sudo apt-get install python3-venv bubblewrap util-linux git
git clone https://github.com/renosaza/RCP.git
cd RCP
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
export RCP_DATA="$PWD/runtime"
export RCP_USERNAME=admin
read -rsp 'Пароль панели: ' RCP_PASSWORD; echo
export RCP_PASSWORD
mkdir -p "$RCP_DATA"
# Сначала запусти локальный llama-server с алиасом rcp-coder на порту 8081.
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 8765 --workers 1
```

Открой `http://127.0.0.1:8765`. Для LAN можно явно изменить адрес прослушивания, но не публикуй этот HTTP-порт в Интернет: Basic Auth без TLS не защищает пароль в недоверенной сети. Для удалённого доступа используй SSH-туннель либо отдельно настроенный HTTPS.

Пример запуска модели и systemd-панели — в `deploy/`. Пути к llama.cpp, весам и библиотекам должны соответствовать установленному окружению. Для моделей с thinking выбран выключенный thinking, чтобы короткие JSON-ответы не обрезались на рассуждении. Мультимодальные проекторы не используются.

## Проверки

```sh
export RCP_DATA="$(mktemp -d)"
export RCP_USERNAME=test-user
export RCP_PASSWORD=test-only-not-a-real-password
.venv/bin/python -B -m unittest test_lab test_autopilot test_chat test_shapes test_reliability_v2 -v
```

60 тестов покрывают сравнение ответов, песочницу, ограничения ресурсов, неизменность регрессий, сохранение прогресса, приоритеты, схемы операций и запуск из чата. Для этих тестов не нужна LLM, но нужен работающий bubblewrap. Реальную способность выбранной модели решать задачи следует проверять отдельно: unit-тесты её не оценивают.

## Хранение и эксплуатация

`RCP_DATA` содержит приватные проекты, сообщения, код и результаты. Не добавляй этот каталог в Git. Одновременно развивается один проект; чат и проверка принятого кода доступны на паузе. Закрытие вкладки не останавливает автопилот.

Размер кандидата ограничен 18 000 символами. Банк регрессионных примеров — 80 тестов / 18 КБ; при приближении к лимиту поиск переходит к улучшению существующего кода. Хранятся последние 20 версий, 5 подробных раундов, 400 событий и около 200 сообщений. При повторных ошибках, нехватке места или превышении времени раунда нужна проверка пользователем. Это ограниченный эксперимент, а не открытая бесконечная эволюция.
