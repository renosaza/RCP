01 / задача

Что должен делать код?

Система ищет реализацию solve(data): один JSON на входе → один JSON на выходе. Это лаборатория функций, не сборщик целых приложений.

Примеры в формате [{"input": ..., "expected": ...}]. Именно по ним проходит отбор программ.

Один запуск одновременно.
До 30 итераций.
Начальный код · необязательно

По умолчанию стартуем с пустой функции. Можно вставить свою реализацию для улучшения.

Как идёт поиск

Модель предлагает код → песочница выполняет его → независимый проверяющий сравнивает ответы → OpenEvolve выбирает родителей следующего поколения.

Критерий: сначала пройденные тесты, затем компактность. Прохождение всех примеров — не доказательство правильности на любых данных.
